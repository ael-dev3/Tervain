Gothic 3

Ardea, from your installation

This page draws Gothic 3's world in the browser from the game files on your computer. Point it at your Gothic 3 folder (or its Data folder): the archives are read here, in this tab. Nothing is uploaded, and no Gothic 3 files are hosted on this site.

Needs an installed, legally owned copy of Gothic 3 (Steam, GOG or disc) and a desktop browser with WebGL 2; Chrome or Edge can remember the folder for next time.

Typical Steam location: C:\Program Files (x86)\Steam\steamapps\common\Gothic 3
