# Original SharedBase diagnostic locale dependencies

Recovered from SharedBase.dll and checked instruction by instruction against the original PE. The package captures LocaleUpdate100a74b6, getPerThreadData100ae542, updateThreadLocale100b1b32 and updateThreadMultibyte100b1387. These methods are source evidence and have not been connected to live SharedBase CRT thread storage.

The formatter passes NULL locale. LocaleUpdate obtains actual SharedBase per-thread data, copies both thread locale pointers, compares them with globals10141468 and10141288 and conditionally updates them when the thread ownership mask permits. It then sets bit2 at thread offset0x70 only if absent and records whether its return cleanup must clear it. A supplied locale follows a separate pointer-copy branch.

getPerThreadData calls100ae4cb and invokes amsg_exit with code0x10 on NULL. This is not an unconditional successful thread getter. Locale globals, the lower thread getter, locking and reference-count dependencies still require retained owners. Game CRT thread data must not stand in for SharedBase data.

The lower getter100ae4cb and provider/decode helpers100ae384 and100ae2f2 are now captured, along with initializePerThreadData100ae40c and callocCrt100aef10. The getter preserves LastError, obtains the provider result, conditionally allocates0x214 bytes, installs thread storage, frees on failed installation and initializes locale and thread-ID fields only after successful installation. Capturing these branches does not create an initialized SharedBase heap, encoded provider or thread slot.

The local NativeSharedStaticTls component now models a declared virtual load of SharedBase for the selected logical thread. It copies the original static TLS template, assigns the first virtual static-module slot0, stores a vector capability at its TEB offset0x2c and resolves the actual buffer alias at0x108. The loader slot is a virtual machine assignment, not a recovered live Windows slot. The component retains the current thread selection and refuses missing or retired thread state. It does not initialize SharedBase CRT per-thread data or execute DLL attach, and is not yet connected to Message.Debug.
