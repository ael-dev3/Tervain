Original initial quest state, before OnGameStartUp

Reproduction
  python -B tools/gothic3/read_initial_quests.py --study <LOCAL_DESKTOP_STUDY>
  Optional --research <RESEARCH_FOLDER> also emits quest_defaults_evidence.json.
  The tool performs offline file/instruction integrity audits only; no native
  binaries are executed. Its native interpretation is guarded by hashes of
  all five reviewed module builds and the original World_MCP source member.

Outputs
  public/gothic3/dialogue/initial-quests.json
  assets/gothic3/dialogue/initial-quests-receipt.json
  assets/gothic3/dialogue/initial-quests-output.json is the compact browser
  receipt; it references the seed bytes/hash and full proof receipt hash.
  Each quest has id, raw numeric status, counters, startedAt {years,days,hours},
  logKeys, complete ordered logPairs, original definitionSource, and packet
  offsets/length/hash when an original compiled runtime packet exists.

INI and runtime overlay semantics
  INI Read0x20338ad0 reads DeliveryCounter values and static quest fields.
  It does not read a Status key. It aligns counters/amounts to the number
  of DeliveryEntities when lengths differ. These 641 audited INIs already
  have matching target/counter lengths (eight empty lists, other values0).
  It does not populate runtime log pairs from the INI LogText field.

  Manager Read0x20024c67 ->0x20348760 first calls LoadQuestsFromInis,
  then reads runtime packet count and overlays by quest name through
  ReadRuntimeData0x2001f447 ->0x20339600. The runtime method sets the
  status and activation time and copies min(runtime-counter-count,
  static-counter-count) counters. Version3 then reads ordered log pairs.
  Counter array reader0x201237e0 reads u8 prefix, u32 count and int32 values.
  Log pair reader0x20343360 reads u8 prefix, u32 count, then per-pair u16
  version and two eCLocString IDs. Engine0x3004089f and0x300126d4 prove
  localization strings delegate to the archive bCString entry reader.

  Reset0x2002f9eb ->0x20336500 calls Invalidate and zeroes every existing
  counter. ResetQuests0x2000bcf8 applies Reset across its array. This export
  does not assume ResetQuests is called during the observed NewGame path;
  it uses the actual serialized overlay and fresh factory/INI state.

Startup order and the first quest run
  Main-menu NewGame Game body0x20195660 calls RestartWorld0x2001d63d
  at0x201957d2, then Session Start0x200087ab at0x20195830 with mode0.
  Session Start body0x20376690 invokes OnInit for modes0/1, then
  OnGameStartUp only for mode0. OnInit registration entry0x10002964
  ->Script_Game body0x100d0470 is distinct from the startup callback.
  OnGameStartUp entry0x10002c07 ->Script_Game body0x100cfb70 constructs
  Xardas_FindXardas at0x100cfdb5 from PE ASCII string0x10213030 and calls
  PSQuestManager::RunQuest through IAT0x10226cc0 at0x100cfdd8.
  Script wrapper0x1000470f ->0x1002b5a0 forwards to Game RunQuest
  0x20007306 ->0x20347f90, which accepts Open0 and requests Running1.
  SetStatus0x2001a519 ->0x20336ff0 captures current clock when entering
  Running. Initial Xardas_FindXardas packet byte256077 length34 is status0,
  activation0 and counter[0] before that startup operation.

Evidence limits
  Direct NewGame RestartWorld-before-Start and Session OnInit-before-startup
  order are byte-proven. This receipt records the actual per-class manager
  deserializer; it does not expand every generic context/property-object
  virtual call from RestartWorld down to that deserializer.
  Remaining OnInit/startup callbacks and entity mutations are separate work.
  startup.applied is false. This seed is not a restored save, a post-startup
  state, or proof that every browser quest/combat callback is implemented.
